Configuration Android — Mode Propriétaire de l'appareil

Sur Android, Brickify doit être configuré en mode Propriétaire de l'appareil pour fonctionner. Cela implique une réinitialisation d'usine et une courte configuration guidée. Cette page vous accompagne à chaque étape.

👀 Avant de commencer

Le mode Propriétaire de l'appareil ne peut pas fonctionner s'il existe déjà un profil de gestion d'organisation. Si votre appareil possède un profil professionnel, utilisez plutôt un appareil personnel non géré pour Brickify.

Configuration

1

Confirmez que vous avez acheté Brickify

Si vous avez déjà appuyé sur « Acheter Brickify » depuis l'application, c'est bon — notez quel compte Google vous avez utilisé, vous devrez vous reconnecter avec ce même compte plus tard. Si vous ne l'avez pas encore acheté, ouvrez d'abord Brickify sur le téléphone et suivez les instructions avant de continuer.

2

Ouvrez cette page sur un second appareil

Vous êtes sur le point d'effacer ce téléphone, vous n'aurez donc plus accès à son écran une fois la réinitialisation lancée. Ouvrez cette page sur un second appareil pour pouvoir suivre les instructions. Il est conseillé de la lire en entier ici dès maintenant.

3

Réinitialisez le téléphone aux paramètres d'usine

Paramètres → Système → Options de réinitialisation → Effacer toutes les données (réinitialisation d'usine) — le libellé exact varie selon le fabricant du téléphone. Cela efface tout ce qui s'y trouve actuellement.

4

Arrêtez-vous à l'écran « Bienvenue »

Une fois la réinitialisation terminée, le téléphone démarre sur un écran « Bienvenue » vierge (parfois « Bonjour ») — n'appuyez pas sur Continuer. Appuyez plutôt sur l'écran au même endroit 6 fois de suite. Un lecteur de code QR s'ouvre.

5

Scannez ce code

Tenez le téléphone stable et inclinez-le légèrement s'il y a des reflets sur l'écran — le lecteur a besoin d'une lecture nette de l'ensemble du code. Une fois le scan effectué, connectez-vous au Wifi si demandé — le téléphone a besoin d'un accès internet pour télécharger Brickify.

6

Appuyez sur Suivant, Accepter et Continuer selon les invites

À partir de là, Brickify s'installe et se configure automatiquement en tant que Propriétaire de l'appareil — il vous suffira de passer par quelques écrans de configuration en chemin. Certains mentionnent « votre organisation » ou « configuration d'un appareil professionnel » — c'est normal. Il s'agit du langage générique utilisé par Android pour toute cette catégorie de configuration, que ce soit pour un service informatique d'entreprise ou, dans ce cas, pour vous. Aucun employeur, établissement scolaire ou tiers n'est impliqué — il s'agit simplement de la configuration administrative propre à Brickify. Une fois installé, ses informations dans les Paramètres sont libellées « Brickify », et non « votre organisation », et expliquent précisément ce qu'il peut et ne peut pas voir.

7

Ouvrez Brickify

La plupart des appareils ouvrent Brickify automatiquement dès la fin de son installation en tant que propriétaire de l'appareil. Si ce n'est pas le cas pour le vôtre, accédez au tiroir d'applications et ouvrez Brickify depuis là.

Ce qui se passe dans l'assistant de configuration de Brickify

Une fois les étapes ci-dessus terminées au niveau de l'appareil, Brickify vous guide à travers sa propre configuration — dans cet ordre, en utilisant les mêmes noms que ceux affichés à l'écran :

1

Code PIN de l'appareil

Un code PIN de verrouillage d'écran pour le téléphone lui-même — celui que votre enfant connaîtra pour déverrouiller et utiliser le téléphone au quotidien.

2

Installer leurs applications

Le téléphone est presque vide après la réinitialisation — installez depuis le Play Store tout ce que vous souhaitez réellement que votre enfant ait, avant de choisir ce qui est autorisé ou bloqué.

3

Ajoutez votre compte Google

Ajoutez votre compte Google au niveau système — le même que celui utilisé pour acheter Brickify, afin que « Restaurer les achats » puisse le retrouver. Choisissez « Je vais utiliser cet appareil » si la question est posée, et non un profil enfant. Si Android propose de trouver automatiquement un compte via votre carte SIM, ignorez cette option et saisissez plutôt l'e-mail manuellement — le compte suggéré automatiquement n'est peut-être pas celui utilisé pour acheter Brickify.

4

Choisissez votre code à 4 chiffres et confirmez-le

Le propre code de Brickify — distinct du code PIN de l'appareil ci-dessus, et celui-ci est pour vous, pas pour votre enfant.

5

Choisissez votre second facteur

Code PIN parent, application d'authentification ou code par e-mail — une seconde couche de sécurité nécessaire avant de déverrouiller manuellement ou de modifier vos paramètres Brickify.

6

Enregistrez vos codes de récupération

Trois codes de secours à usage unique. Notez-les — ils ne seront plus jamais affichés.

7

Configurez votre profil

Configurez les profils du téléphone — nommez le premier et choisissez les applications qu'il bloque. Un profil par défaut est requis ; c'est celui vers lequel le téléphone revient par défaut. Autant d'autres profils que vous le souhaitez peuvent être programmés en plus de celui-ci, pour que le téléphone bascule automatiquement entre eux. Pas d'inquiétude — vous pouvez aussi configurer tout cela plus tard.

8

Alertes parent

Brickify vous envoie un e-mail si quelque chose nécessite votre attention — l'appareil ne répond plus, sa protection est retirée, ou (malgré le blocage) une nouvelle application apparaît. Utilisez ici votre propre adresse e-mail, pas celle de votre enfant.

9

Autorisations Android

Activez le Service d'accessibilité — c'est ce qui bloque réellement les applications. L'Administrateur de l'appareil est déjà actif automatiquement. Il vérifie uniquement quelle application est au premier plan, sur l'appareil lui-même — rien n'est enregistré, stocké ni envoyé où que ce soit. Comme cet appareil a été configuré en scannant un code QR plutôt qu'en installant depuis le Play Store, Android peut afficher l'interrupteur comme un « paramètre restreint » la première fois — les instructions affichées dans l'application sur cet écran vous guident à travers l'étape unique « Autoriser les paramètres restreints » pour le déverrouiller.

10

Déverrouillez Brickify

Payez, ou appuyez sur Restaurer un achat précédent si vous l'avez déjà acheté — ouvrez d'abord l'application Play Store une fois si elle ne retrouve pas l'achat immédiatement, pour lui permettre d'enregistrer le compte. Votre paiement est lié à votre compte Google via Play Billing, et non à cette copie précise de l'application installée sur ce téléphone en particulier — la restauration retrouve donc ce même achat et déverrouille de nouveau Brickify, sans nouveau prélèvement.
